AGENT AVAILABLE: /documentation

SYNTAX: /documentation <scope> <path>

================================================================================
SCOPES
================================================================================

FILE      - Document a single Python file with docstrings
          Example: /documentation file zibanu/django/rest_framework/decorators.py

DIRECTORY - Document entire package/directory with consistent style
          Example: /documentation directory zibanu/django/auth

README    - Generate comprehensive README.md for a package (EN + ES)
          Example: /documentation readme zibanu/django/repository

SWAGGER   - Generate OpenAPI/Swagger documentation for endpoints (EN + ES YAML)
          Example: /documentation swagger zibanu/django/auth

================================================================================
DOCUMENTATION FORMAT
================================================================================

Google-style docstrings with:
  ✓ Brief description
  ✓ Args with types and descriptions
  ✓ Returns with type and description
  ✓ Raises (exceptions that may be raised)
  ✓ Example usage
  ✓ Type hints

README includes:
  ✓ Overview and purpose
  ✓ Installation instructions
  ✓ Quick start example
  ✓ Features list
  ✓ Detailed usage guide
  ✓ API reference
  ✓ Configuration options
  ✓ Testing instructions
